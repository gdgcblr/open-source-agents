# PR Review Assistant

> An agent that generates concise, actionable review comments for a GitHub Pull Request using a large language model.

---

## Overview

### Problem Statement & Intended Users
- **Problem**: Reviewing large PRs is time‑consuming and error‑prone. Reviewers often miss style issues, potential bugs, or documentation gaps.
- **Intended Users**: Developers who submit PRs on GitHub and maintainers who want to accelerate the review process.

### Key Features
- Fetches the PR diff via the GitHub REST API.
- Summarizes changes and highlights potential issues (style, security, missing tests, etc.).
- Generates a markdown‑formatted comment ready to be posted back to the PR.
- Configurable model and temperature.

---

## Technical Stack

- **Language & Runtime**: Python 3.11+
- **Agent Framework**: Vanilla script using `requests` + OpenAI/Gemini API.
- **Models**: Gemini 1.5 Flash (default) – configurable via `MODEL_NAME`.
- **External APIs / Tools**: GitHub REST API (requires a personal access token), LLM provider API.

---

## Architecture & Data Flow

```
[User Input] -- GitHub PR URL --> [Agent] -- fetch diff --> [LLM] -- generate review --> [Markdown comment]
```

---

## Prerequisites

- Python 3.11+ installed.
- `pip` (or `uv`) for dependency management.
- A GitHub Personal Access Token with `repo` scope.
- An LLM API key for the chosen model (e.g., Gemini, OpenAI).

---

## Installation & Setup

1. **Navigate to the project directory**
   ```bash
   cd agents/pr-review-assistant
   ```
2. **Create a virtual environment & install dependencies**
   ```bash
   python -m venv .venv
   .venv\Scripts\activate   # Windows
   pip install -r requirements.txt
   ```
3. **Configure environment variables**
   ```bash
   cp .env.example .env
   # Edit .env and fill in the placeholders.
   ```

---

## Configuration & Environment Variables

| Variable Name | Required | Default | Description |
| :--- | :--- | :--- | :--- |
| `GITHUB_TOKEN` | Yes | – | Personal Access Token for GitHub API |
| `API_KEY` | Yes | – | LLM provider API key |
| `MODEL_NAME` | No | `gemini-1.5-flash` | Identifier of the model to use |
| `LOG_LEVEL` | No | `info` | Logging verbosity |

---

## How to Run

```bash
python src/main.py --pr https://github.com/<owner>/<repo>/pull/<number>
```

Optional flags:
- `--model <model_name>` – override the default model.
- `--max-tokens <int>` – limit the LLM response length.

## Known Limitations

- Relies on the quality of the diff; binary files are ignored.
- Model may hallucinate suggestions; always review generated comments.
- Rate‑limited by both GitHub and LLM APIs.

---

## Security & Privacy Considerations

- **Secrets Handling**: Tokens are loaded from `.env` and never committed.
- **Data Privacy**: PR diff is sent to the LLM provider; ensure you are comfortable with this data exposure.
- **Safety**: The agent only reads data and calls the LLM; no commands are executed on the host.
