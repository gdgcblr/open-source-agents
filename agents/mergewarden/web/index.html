Architecture

Hard rules first, judgement second, a human last.

A Google ADK pipeline. Cyan steps are deterministic code; violet steps call Gemini. The verdict is computed from the findings by code, never by the model.

Trust rules

  1. Rules come from the base branch. A PR can't weaken the guide it is judged by.
  2. PR code is never executed on the host. Files are read from a git archive snapshot; installs run only in a resource-limited container.
  3. AI can add, never erase. Gemini findings can't remove a deterministic finding, can't be blocker, and can't set the verdict.
  4. Prove it or demote it. Each AI finding must quote the submission. Quotes that aren't found become info.
  5. Untrusted text stays data. Instructions aimed at the reviewer are flagged as prompt injection for a human.
  6. Secrets are masked. A review comment never re-publishes the key it found.
