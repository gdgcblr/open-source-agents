# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 2.0.x   | :white_check_mark: |
| < 2.0   | :x:                |

## Reporting a Vulnerability

We take the security of OSS Pulse Agent seriously. If you discover or suspect a security vulnerability, please do NOT create a public GitHub issue.

Instead, please responsibly disclose it by:
1. Sending an email with reproduction steps and impact to security maintainers.
2. Or opening a [Private Security Advisory](https://github.com/gdgcblr/open-source-agents/security/advisories) on GitHub.

### What to Include
- Detailed description of the vulnerability.
- Proof-of-concept script, curl commands, or steps to reproduce.
- Any potential remediations or patches if available.

### Response Timeline
- **Initial Response:** Within 48 hours acknowledging receipt.
- **Triage & Assessment:** Within 5 business days.
- **Resolution & Release:** Coordinated disclosure once an update is published.
