# AI Document Action Extractor

> Extract structured action items from meeting notes and other text, with optional Google Gemini-powered extraction.

---

## Overview

### Problem Statement & Intended Users

- **Problem:** Meeting notes often contain tasks, owners, and deadlines that are difficult to track manually.
- **Intended Users:** Developers, students, project teams, and anyone who wants to organize action items from text documents.

### Key Features

- Extract tasks, owners, deadlines, priorities, and supporting evidence.
- Use Google Gemini for live AI extraction.
- Run a deterministic offline demo without an API key.
- Export action items to CSV.
- Avoid inventing missing owners or deadlines.
- Validate functionality with automated pytest tests.

---

## Technical Stack

- **Language & Runtime:** Python 3.10+
- **Agent Framework / Core Library:** Python script using the Google Gen AI SDK
- **Model:** Gemini 3.8 Flash by default; configurable through `MODEL_NAME`
- **External APIs / Tools:** Google Gemini API, python-dotenv, pytest, Python CSV and JSON libraries

---

## Architecture & Data Flow

The application provides a menu-driven interface in `main.py`. The offline demo displays predefined example results. In live mode, the application passes text to `extractor.py`, which validates the API key, sends the text to the configured Gemini model, parses the structured JSON response, and returns action items. Results can be displayed in the terminal and exported to `actions.csv`.

**Flow:** User input → Main menu → Offline demo or Gemini extraction → Structured action items → Terminal / CSV export.

---

## Prerequisites

- Python 3.10 or newer
- `pip`
- Internet access and a valid Google Gemini API key for live extraction only

The offline demo and automated tests do not require a Gemini API key.

---

## Installation & Setup

1. **Navigate to the project directory:**

   ```bash
   cd agents/document-action-extractor
   ```

2. **Create and activate a virtual environment:**

   ```bash
   python3 -m venv .venv
   source .venv/bin/activate
   ```

3. **Install dependencies:**

   ```bash
   pip install -r requirements.txt
   ```

4. **Configure environment variables for live extraction, if needed:**

   ```bash
   cp .env.example .env
   ```

   Add your own Gemini API key to `.env`. Do not put real credentials in `.env.example`.

---

## Configuration & Environment Variables

| Variable | Required | Default | Description |
|---|---|---|---|
| `GEMINI_API_KEY` | Yes for live extraction | None | API key used to authenticate with Google Gemini |
| `MODEL_NAME` | No | `gemini-3.8-flash` | Gemini model identifier |

The offline demo does not require either variable. Use a model name available to your Google API account.

---

## How to Run

From this directory, activate the virtual environment and run:

```bash
python main.py
```

- Choose option `1` to display predefined offline demo results.
- Choose option `2` to extract action items from the sample document using Gemini.
- Choose option `3` to enter your own text for live extraction.
- Follow the prompt to export results to `actions.csv` when offered.

Live extraction requires a valid API key, internet access, and an available model.

## Example Input & Output

### Example Input

```text
Rahul must finish API testing by October 26.
```

### Example Output

```text
Task: Finish API testing
Owner: Rahul
Deadline: October 26
Priority: Not specified
Evidence: Rahul must finish API testing by October 26.
```

This is an illustrative example of the expected structured fields. Actual live results are generated by Gemini and may vary. The offline demo uses predefined results rather than performing AI inference.

## How to Test

Run the automated test suite from the project directory:

```bash
python -m pytest -q
```

The tests verify the offline demo's sample items, required output fields, and preservation of relative dates.

For a manual check, run `python main.py` and choose option `1`. Confirm that the sample action items display correctly. CSV export can also be checked by opening the generated `actions.csv`.

---

## Known Limitations

- The offline demo displays predefined results and does not perform AI inference.
- Live extraction requires a valid Gemini API key, network access, and an available model.
- Relative dates such as "next Monday" are preserved as written and are not converted into calendar dates.
- AI-generated results may be incomplete or incorrect; verify action items before relying on them.
- The application currently processes text input rather than directly reading PDF or Word documents.

---

## Security & Privacy Considerations

- **Secrets Handling:** Credentials are loaded from environment variables or the local `.env` file. The `.env` file must not be committed or shared.
- **Data Privacy:** In live mode, submitted text is sent to the configured Google Gemini API. Do not submit confidential or personal information unless you are authorized to do so.
- **Safety:** The application extracts structured text and does not execute extracted tasks or arbitrary shell commands.
- **Generated Files:** The `actions.csv` output, virtual environment, and Python cache files are intended to remain local and ignored by Git.
