merge-mentor

From "I know TypeScript" to your first merged PR. Pick your language and level, choose a project, then an issue, and get the explanation and fix plan.

Projects

Choose a language and level, then press Find projects. Pick a project to see its free issues.

Explanation

Select an issue to see what it means, where it happens, and how to fix it.
merge-mentor only reads public GitHub data. It never edits code or opens pull requests: you review the suggested fix and raise the PR yourself.
