What it does

More than a chatbot — evidence-based checks, honest rent data, anonymous community, vacating board.

AI rental safety (listing + chat)

  • Rule IDs (RF-001…) with evidence excerpts from your text
  • Risk tiers: low → critical — never “verified safe”
  • Deterministic engine; LLM optional for orchestration only

Transparent Bengaluru rent ranges

  • Whitefield, Koramangala, HSR, Bellandur, and more
  • Labels illustrative vs observed; no guess when data is thin

Anonymous tenant experiences

  • Moderation, PII redaction, negative-but-fair reviews allowed
  • Secret edit tokens — not shown in public search

Vacating / room availability

  • Active → filled / withdrawn / expired lifecycle
  • Private contact; lease-permission reminders

Agreement checklist

  • Source-backed references; no invented deposit cap
  • Law vs guidance vs practical steps clearly separated

Interactive preview

Client-side demo mirrors common red flags. Full analysis runs in Python via main.py or Streamlit.

Run it

Copy commands — from agents/rentrakshak/

Docker smoke
docker compose build
docker compose run --rm test
docker compose run --rm cli
CLI report (no API key)
python main.py --listing @tests/fixtures/suspicious_listing.txt
Local Gemma (Ollama)
pip install -r requirements-ollama.txt
export RENTRAKSHAK_LLM_BACKEND=ollama
export RENTRAKSHAK_OLLAMA_MODEL=gemma3:4b
adk web adk_agent
Streamlit UI
streamlit run ui/streamlit_app.py
