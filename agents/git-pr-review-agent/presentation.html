The Motivation

Why Maintainers Are Burning Out

Code reviews are bogged down by repetitive hygiene checks and accidental secret leaks.

Review Fatigue

Maintainers spend 60%+ of their review cycles checking formatting, syntax, and missing tests rather than architecture.

Secret Leaks

Developers accidentally commit Google AI keys, GitHub PATs, and AWS tokens. Standard LLMs can hallucinate and miss them.

Vague PRs

PR descriptions are often left empty or vague ('bug fixes'), breaking traceability and slowing release cycles.

Privacy Risks

Proprietary enterprise code cannot be blindly sent over the internet to external third-party cloud APIs.

Core Innovation

5-Layer Guardrail Defense

Defense-in-depth: Never rely on probabilistic LLMs alone for critical repository security.

Layer 1 Context & DOS Guard Strips noise & lockfiles (package-lock.json) so giant diffs don't crash or blow out LLM token limits.
Layer 2 Secret Shield (Pre-LLM) Zero-hallucination static regex audit for Google AI keys (AIzaSy...), GitHub PATs, and AWS tokens.
Layer 3 Anti-Pattern Execution Guard Catches arbitrary execution risks: eval(), exec(), subprocess(shell=True), and raw SQL injections.
Layer 4 Air-Gapped Privacy Guard 100% offline local review on Google Gemma 2 (gemma2:2b) with zero external network traffic.
Layer 5 Verdict Escalation Guard The LLM is forbidden from approving unsafe code. Critical flaws automatically force REQUEST_CHANGES.

Engine Overview

Dual-Engine Model Tier

Intentionally built around the Google AI ecosystem: Gemini for reasoning + Gemma 2 for on-box privacy.

🔒 Privacy Tier: Google Gemma 2 (Local)

  • Runs 100% locally and offline via Ollama (gemma2:2b).
  • Zero cloud egress: Confidential code stays completely on-box.
  • Pre-LLM secret scanner catches Google API keys and tokens.
  • Detects dangerous execution anti-patterns: eval(), exec().
  • Ideal for air-gapped CI and privacy-sensitive enterprises.

⚡ Architect Tier: Google Gemini 2.5 Flash

  • Performs deep multi-file semantic reasoning and architecture review.
  • Evaluates breaking changes and backward compatibility.
  • Auto-generates standardized Conventional PR summaries.
  • Produces custom testing and verification checklists.
  • Deterministic Mock Mode ensures 100% CI test pass rate.
