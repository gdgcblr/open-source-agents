⚠️ Industry Problem Statement

The Real Cost of Documentation Debt

In modern agile teams, code moves at lightning speed while documentation rots.

🥀
Stale & Rotting Docs
Developers update code and forget READMEs. New joiners and customers waste hours deciphering broken examples and obsolete APIs.
🔀
User vs. Dev Docs Chaos
Projects mash internal private classes and public installation guides together into one huge, confusing README file.
💸
Token Waste & LLM Costs
Naive LLM generators dump entire 100,000-line codebases into prompts every time a 1-line commit is made, burning API budgets.
💡 The Innovation

Enter CodeLens Doc Gen

A deterministic static analyzer paired with Google Gemini intelligence for continuous, dual-tiered documentation.

🔬
Deep AST Parsing
Analyzes Python Abstract Syntax Trees to extract exact class hierarchies, public vs. private functions, docstrings, and signatures without regex guesswork.
🧠
Dual-Tier Categorization
Separates output into user-docs/ (APIs, usage, config) and dev-docs/ (architecture, internals, data flow).
⚡
Diff-Aware Incremental Sync
Inspects git diff commits and updates only the documentation files affected by the changed code. Zero wasted tokens.

⚙️ Engineering Depth

Static AST Parsing & Token Condensation

Why AST beats Raw Code Dump

Dumping raw files into an LLM leaks implementation secrets, risks hallucination, and explodes token limits.

CodeLens parses files using Python's native ast module to distill code down to pure semantic metadata:

Class Inheritance Trees Docstrings & Comments Type Annotations Private _func() vs Public
The Token Condensation Layer

Before calling Gemini, condense_for_llm() converts the AST tree into a hyper-efficient structural digest:

File: codelens/config.py (Python) Class: Config - gemini_api_key: str - gemini_model: str = "gemini-3.8-flash" - output_dir: str = "./docs_output" Function: validate_config(config: Config)

✓ 92% token reduction compared to sending raw source code.

🗂️ Intelligent Categorization

Categorization Strategy: Dev vs. User Docs

User Docs (user-docs/)

Targeted at developers consuming the application, end users, and API clients:

  • CLI commands, arguments, and options
  • Configuration keys & environment variables
  • Public SDK APIs and return types
  • Step-by-step setup and quickstart guides
Developer Docs (dev-docs/)

Targeted at project maintainers and internal contributors:

  • Internal architecture diagrams & module flows
  • Private methods and implementation details
  • State management and persistence schemes
  • Unit testing strategies and extension hooks
Strategy Pattern Resilience If Gemini API is offline, rate-limited, or no key is provided, the engine gracefully falls back to deterministic rule-based heuristics. The tool never crashes.
